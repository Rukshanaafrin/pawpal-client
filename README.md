# PawPal - Pet Adoption Platform

## Project Purpose

PawPal is a full-stack Pet Adoption Platform built with the MERN Stack. Users can browse pets, view detailed information, submit adoption requests, and manage their requests. Pet owners can add, update, delete listings and manage adoption requests.

## Features

- Firebase Authentication (Email/Password & Google Login)
- Browse all available pets with detailed information
- Search and filter pets by species and name
- Submit and manage adoption requests
- Add, update and delete pet listings
- Approve and reject adoption requests
- Responsive design for mobile, tablet and desktop
- Custom Loading Spinner and 404 Page
- Framer Motion animations
- Dark/Light theme toggle
